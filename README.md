# Sales Data Analysis

## 📊 Project Overview

This project analyzes sales data to identify important trends and patterns in sales performance.

The dataset contains information such as order dates, products, categories, regions, and quantities. The project focuses on understanding sales performance and presenting useful insights through data analysis and visualization.

## 🎯 Objectives

* Analyze overall sales performance
* Identify sales trends over time
* Compare sales across different categories
* Analyze regional sales performance
* Understand product and quantity patterns
* Create meaningful visualizations from the sales data

## 📁 Dataset

The dataset contains the following main columns:

* **Order_Date** – Date when the order was placed
* **Category** – Product category
* **Product** – Product name
* **Region** – Sales region
* **Quantity** – Number of products sold
* **Sales** – Sales amount

## 🛠️ Tools & Technologies

* Tableau

## 📈 Analysis

The project is designed to analyze:

1. **Sales Over Time** – Understand how sales change over different dates.
2. **Category Analysis** – Compare sales between product categories.
3. **Regional Analysis** – Identify regions with higher or lower sales.
4. **Product Analysis** – Understand product-level sales performance.
5. **Quantity Analysis** – Examine the quantity of products sold.
